Revisão dos dados

Ocorrências de toda a base, com arquivo, página, mês, clínica e profissional. Totais gerais sem detalhamento não permitem atribuir a diferença a uma clínica.

Como os dados são calculados

Os acumulados somam as linhas mensais disponíveis no PDF. São ocorrências mensais, sem deduplicação de pacientes entre meses. Taxas e médias são recalculadas sobre os totais, sem média simples dos percentuais.

A visão por clínica utiliza a tabela de médicos. Consultores e médicos são analisados separadamente. Os totais impressos dos PDFs são preservados para conferência.

“Liberado / Alta / Desmame” é uma categoria única. Na quantidade prevista, aproveitamento geral = readeriu ÷ total; entre elegíveis = readeriu ÷ (total − liberado / alta / desmame); entre decisões = readeriu ÷ (readeriu + não readeriu).

Os dados permitem identificar diferenças e tendências; causas e metas dependem de validação operacional.
